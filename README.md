# ProgHorarioClase

Motor de asignación automática de horarios de clases (timetable problem).
Proyecto Núcleo 2, 2026-2, Universidad El Bosque. Grupo 5.

Integrantes: Jesús David Beltrán Zárate, Juan Sebastián Albarracín Isaza,
Daniel Felipe Delgadillo Sepúlveda y Martín Daniel Porto Gutiérrez.
Docente: Ing. Samuel Galindo Pinzón.

## Contenido

- `motor-horarios/` prototipo del motor en Java 21 (backtracking con la sesión más
  restringida primero, restricciones con el patrón Strategy) y resultados de las mediciones.
  Las instrucciones para compilar y ejecutar están en su README.
- `docs/diagramas/` fuentes PlantUML (.puml) e imágenes de los diagramas de clases,
  actividades, secuencia, componentes y del DER.
- `docs/mockups/` wireframes de la interfaz en HTML.
- `docs/entregables/` Documento Maestro y Documento de Anexos del Módulo 2.
